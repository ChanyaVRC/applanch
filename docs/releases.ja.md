# リリースノート

バージョンごとのユーザー向け変更点を記載しています。完全なコミット履歴とダウンロードは [GitHub リリースページ](https://github.com/ChanyaVRC/applanch/releases) をご覧ください。

---

## v0.6.2 — 2026年4月13日

Quick Add の UX 改善とローカライズバグ修正を含むパッチリリースです。

### 新機能

- **Quick Add のプレースホルダー表示** — Quick Add のアプリ入力欄とカテゴリ入力欄が空のとき、何を入力するかを示すプレースホルダーテキストを表示するようになりました。

### 改善

- **カテゴリサイドバーのラベル折り返し** — サイドバーのカテゴリ名が長い場合、切り捨てではなく折り返して表示されるようになりました。
- **コントロールスタイルの統一** — 入力欄、ダイアログ、その他のコントロールで共有スタイルを見直し、アプリ全体の見た目の一貫性を向上しました。
- **テーマのブラシ粒度の向上** — メッセージダイアログ、スクロールバー、通知ホバー状態、プレリリースバッジ、パス未検出バッジ、サイドバーのピンアイコンに対してより細かいテーマブラシを追加しました。テーマからこれらの要素を個別に指定できます。

### 修正

- **Quick Add カテゴリのローカライズ反映** — アプリの言語を変更しても、Quick Add のカテゴリドロップダウンの選択肢が以前の言語のまま更新されない問題を修正しました。

## v0.6.1 — 2026年4月11日

カテゴリサイドバーのドラッグ＆ドロップ時の安定性と操作感を改善するパッチリリースです。

### 修正

- **サイドバー DnD 時の折りたたみ判定の一貫性** — 折りたたみ判定処理を `CategorySidebarControl` 側に移し、ホバーゾーン・サイドバー本体・ドラッグセッション終了の各経路で一貫した挙動になるよう整理しました。
- **ドラッグ遷移時の意図しない折りたたみ** — 起動アイテムのドラッグ中に、ホバーゾーンとサイドバー本体の境界を移動した際にサイドバーが意図せず閉じるケースを防止しました。

### 改善

- **DnD 処理責務の分離** — サイドバー内で完結する DragEnter/DragLeave 処理をサイドバーコントロールへ集約し、カテゴリ移動適用ロジックは `MainWindow` 側に維持しました。

## v0.6.0 — 2026年4月11日

v0.6 系列の安定版リリースです。

### 改善

- **更新適用フローの統一** — ヘッダー、バナー、設定画面の更新適用トリガーを統一し、どこから実行しても同じフローで適用されるようにしました。
- **更新実行状態の安全性向上** — 更新適用中の二重実行を防止し、適用中 UI 状態の扱いを改善しました。
- **更新メタデータ取得の回復性** — 一時的な取得失敗後に、リリースメタデータキャッシュが正しく回復するようにしました。
- **セマンティックバージョン処理** — プレリリース比較の優先順位を改善し、不正なセマンティックバージョン形式の扱いを厳格化しました。

### 修正

- **アイコンモードのドラッグ並び替え閾値** — アイコンモードでのドラッグ＆ドロップ並び替え時に、挿入判定軸が正しく使われるよう修正しました。
- **アイコンモードの並び替えアニメーション** — アイコンタイル並び替え時に、横方向および斜め方向の遷移アニメーションが正しく動作するよう修正しました。

### 補足

- `v0.6.0-rc.1` で検証した内容に加え、更新信頼性とアイコンモード操作品質の安定化修正を取り込んでいます。

## v0.6.0-rc.1 — 2026年4月11日

次期 applanch のリリース候補版（Release Candidate）です。

### 新機能

- **プレリリース更新のオプトイン** — プレリリース更新チャネルを受け取るかどうかを、設定で選べるようになりました。
- **更新対象バージョンの選択** — 設定画面で、利用可能な更新バージョンから選択できるようになりました。

### 改善

- **プレリリース表示の強化** — メイン画面でプレリリースであることをより分かりやすく表示し、プレリリースバッジの見た目とテーマへの追従性を改善しました。
- **更新メタデータ取得フロー** — リリース情報の取得フローとキャッシュ挙動を整理し、一時的な取得失敗後に古い失敗状態が残らないよう改善しました。
- **更新用 HTTP クライアント** — 更新処理で利用する共有 `HttpClient` の利用方法と初期化挙動を改善しました。

### 補足

- 本バージョンは、安定版リリース前の検証を目的とした `-rc` プレリリースです。

## v0.5.7 — 2026年4月9日

- **設定モデル内部整理** — 設定ドラフト更新の経路を統合し、可読性と保守性を改善しました。

## v0.5.0 — 2026年4月6日

### 新機能

- **コンテキストメニューの起動時追加** — 設定 → スタートアップ に、起動時に Windows エクスプローラーの *Register with Applanch* コンテキストメニューを追加するトグルが加わりました（デフォルトで有効）。
- **コンテキストメニューの削除** — 設定 → スタートアップ に *Applanch コンテキストメニューを削除* ボタンが追加されました。既存のエクスプローラーコンテキストメニューエントリーを即座に削除します。

### 改善

- **ユーティリティアクション** — 設定に *診断情報をコピー*（アプリバージョン・OS・ロケール・ログフォルダーパスなどをクリップボードにコピー）と *ログフォルダーを開く*（エクスプローラーで applanch のログディレクトリを開く）アクションが追加されました。
- **インストーラー** — Windows インストーラーが日本語に対応しました。ウィザードのアイコンを更新しました。

## v0.4.4 — 2026年4月4日

- **Windows エクスプローラーコンテキストメニュー** — スパースパッケージとして登録されている場合、Windows 11 でのファイルやフォルダーの右クリックメニューに *Register with Applanch* エントリーが追加されます。
